# Big-brick-guy-
Hand made minifigures

## Adding Images

You can add images to this repository in a few ways:

### 1. **In the README.md**
Use Markdown syntax to display images:
```markdown
![Alt text](path/to/image.jpg)
```

Example:
```markdown
![Minifigure Collection](images/collection.jpg)
```

### 2. **Create an Images Folder**
Organize your images by creating an `images/` folder:
```
Big-brick-guy-/
├── README.md
└── images/
    ├── minifig1.jpg
    ├── minifig2.jpg
    └── gallery.md
```

### 3. **Display Multiple Images in Gallery**
Create an `images/gallery.md` file with your gallery:
```markdown
# Minifigure Gallery

## Custom Designs

![Design 1](minifig1.jpg)

![Design 2](minifig2.jpg)
```

### 4. **Supported Image Formats**
- `.jpg` / `.jpeg`
- `.png`
- `.gif`
- `.webp`

### Steps to Add Images:
1. Create an `images/` folder in your repository
2. Upload your minifigure photos
3. Reference them in your README using: `![Description](images/filename.jpg)`
4. Commit and push to GitHub

### Example in README:
```markdown
# Featured Minifigures

![My Custom Minifig](images/custom-build.jpg)
```
